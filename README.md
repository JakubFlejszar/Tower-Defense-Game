# Tower Defense Game

A medieval tower defense game where you defend your castle by building towers to stop approaching bandits.

## Castle
You can click your castle to upgrade it. Max 3 levels, once per wave, so you have to time it right. Each upgrade gives +25 HP and +25 max HP.

## Tower Building
 Building towers to defend your castle is simple, just left click on the map where you want your tower and it appears. You can upgrade each tower, max 3 levels, once per wave. Each upgrade gives +5 attack damage.
 
## Waves
 Currently there are 3 waves in the game. With every wave the number of bandits increases, and so does their spawn rate, so there are more of them, and they come faster. After every wave the game pauses, so you can rest from all that exhausting strategy planning. Press the “Next wave” button on screen to continue.

## Victory
 Just kill them all.

## Defeat
If bandits destroy your castle, you lose. <sub>Loser</sub>

## Download

You can play the game without Unity, just grab the zip from the [Releases](../../releases) page, unpack it and run the .exe.

## Building it yourself

The project uses 3 paid packs from the Unity Asset Store, which are not included in this repo because of their license. To open and build the project in Unity, you need to download them yourself:

- [Handpainted Grass & Ground Textures](https://assetstore.unity.com/packages/2d/textures-materials/nature/handpainted-grass-ground-textures-free-terrain-tool-urp-hdrp-187634)
- [Medieval Warrior Pack](https://assetstore.unity.com/packages/2d/characters/medieval-warrior-pack-159577)
- [Middle Age - Medieval Action Sound FX Pack](https://assetstore.unity.com/packages/audio/sound-fx/middle-age-medieval-action-sound-fx-pack-54030)
